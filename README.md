## Sobre mim

Atuo como desenvolvedor Full Stack, com experiência em automação de testes e qualidade de software (QA). Trabalho no desenvolvimento de aplicações web utilizando Vue.js, Nuxt.js, Node.js e MongoDB, além de aplicar automação de testes para garantir a qualidade dos sistemas.

**Principais habilidades:**

Desenvolvimento Full Stack (Vue.js, Nuxt.js, Node.js, MongoDB, JavaScript, TypeScript) · Automação de Testes (Playwright, Cypress, Appium, WebdriverIO) · Qualidade de Software (planejamento e execução de testes, BDD, gestão de defeitos) · Banco de Dados e Backend (MongoDB, APIs, GraphQL) · Infraestrutura e Deploy (VPS, CI/CD, monitoramento) · Metodologias ágeis (Scrum, Kanban)

Sempre em busca de aprendizado e inovação, combinando desenvolvimento e testes para criar soluções eficientes e de alta qualidade.
